# Python Profile & Stats Analyzer

Оконное приложение на Python (`tkinter`), созданное в рамках практического задания. Программа анализирует статистику матчей, вычисляет средний балл и сохраняет отчеты в текстовые файлы

## Описание функций
- Ввод никнейма игрока и результатов матчей через запятую.
- Автоматический расчет среднего балла, максимумов и минимумов (на базе встроенных функций).
- Формирование структурированного словаря с данными.
- Сохранение результатов в текстовый файл с обработкой ошибок (`try-except`).

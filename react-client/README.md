# ZemNyux React client

Окремий локальний React-застосунок для Django-проєкту ZemNyux Inc. Інтерфейс отримує відділи, працівників, проєкти, клієнтів і договори через `GET /api/company/`.

## Запуск

1. Переконайтесь, що Django працює на `http://127.0.0.1:8000`.
2. У цій папці виконайте `npm install`.
3. Запустіть `npm run dev` і відкрийте URL, виведений Vite (типово `http://localhost:5173`).

За потреби створіть `.env` на основі `.env.example` і задайте `VITE_API_URL`. Django API та налаштування CORS для React dev-сервера знаходяться у локальному бекенді: `company/views.py`, маршрут — `company_site/urls.py`.

У застосунку є оглядова панель, списки реєстрів із пошуком, експорт JSON і індикатор стану реального підключення. Якщо сервер недоступний, панель пояснює, як його запустити.

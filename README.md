# Корпоративний веб-портал ZemNyux Inc. (Django Nested Routes)

Веб-проєкт на **Django 6.1** (Python 3.14), що демонструє повноцінну реалізацію архітектури корпоративного веб-сайту з **вкладеними маршрутами** (`nested routes`), динамічними параметрами (`<slug:country>`), регулярними виразами (`re_path`), автоматичною переадресацією, кастомною сторінкою помилки 404, сучасним UI/UX дизайном та кастомними middleware.

---

## Структура розділів та маршрутизації

### Основні розділи (6 розділів):
1. **Головна** (`/`) — презентаційний hero-банер, ключові метрики компанії, напрямки діяльності та швидкий перехід.
2. **Про компанію** (`/about/`, підтримує підшляхи через `re_path`) — місія, корпоративні принципи та інженерні стандарти.
3. **Керівництво** (`/management/`, з `re_path`) — склад ради директорів (CEO, CTO, Lead Architect, VP of Growth) з профілями та біографіями.
4. **Новини** (`/news/`, з `re_path`) — актуальні події, релізи платформи Yellow Submarine та галузеві сертифікації.
5. **Філії** (`/branches/`) — окремий додаток `branches` з каталогом міжнародних хабів та розділом історії.
6. **Контакти** (`/contacts/`) — головний інформаційний центр, гаряча лінія та вибір локального представництва.

### Підрозділи (по 3-4 підрозділи в кожному напрямку):
* **Підрозділи додатку `branches`:**
  * `/branches/london/` (також `/branches/London/`) — фінтех-хаб у Лондоні.
  * `/branches/paris/` (також `/branches/Paris/`) — центр інновацій та дизайну в Парижі.
  * `/branches/berlin/` (також `/branches/Berlin/`) — R&D кластер штучного інтелекту в Берліні.
  * `/branches/history/` — розділ історії компанії з вкладеними сторінками:
    * `/branches/history/dates/` — інтерактивна хронологічна шкала ключових дат (1878–2026).
    * `/branches/history/facts/` — визначні факти про інфраструктуру та досягнення.
* **Підрозділи контактів (`core:contacts_country`):**
  * `/contacts/ukraine/` — центри розробки в Україні (Київ, Одеса).
  * `/contacts/france/` — французький офіс зв'язків (Париж).
  * `/contacts/austria/` — центральноєвропейський хаб (Відень).
  * `/contacts/germany/` — німецьке представництво (Берлін).

## Обробка помилок та переадресація

1. **Кастомна сторінка 404 (`404.html`):**
   * При переході на будь-яку неіснуючу адресу (наприклад, `/contacts/unknown-country/` або `/any-random-url/`) відображається стилізована сторінка 404 з повідомленням, запитуваним шляхом та кнопками швидкого повернення.
   * Підключено через `handler404 = 'core.views.custom_404_view'` у `company_site/urls.py`.
2. **Автоматична переадресація (Redirects):**
   * `/branch/` &rarr; `302 Redirect` на `/branches/`
   * `/contact/` &rarr; `302 Redirect` на `/contacts/`
   * `/history/` &rarr; `302 Redirect` на `/branches/history/`

## UI / UX та статика

* **Стилі (`static/css/style.css`):**
  * Корпоративна кольорова гама (Navy, Slate, Vibrant Blue, Emerald, Amber).
  * Адаптивна фіксована шапка сайту (Sticky Navbar) з автоматичним підсвічуванням активного пункту меню через `request.path`.
  * Інформативні картки (`card-grid`), лічильники статистики, кольорові бейджі.
  * Навігаційні ланцюжки («хлібні крихти» / Breadcrumbs) на всіх вкладених сторінках.
  * Інтерактивна вертикальна шкала часу (Timeline) для дат.
  * Повноцінний адаптивний футер із посиланнями на всі рівні сайту.

---

## Кастомні Middleware

1. **`log_requests`** (функціональний): фіксує метод, URL, статус-код і точний час виконання кожного HTTP-запиту в консоль.
2. **`CustomHeaderMiddleware`** (класовий): додає HTTP-заголовки `X-Powered-By: ZemNyux 26/02/2026` та `X-Company-Name: ZemNyux Inc.`.
